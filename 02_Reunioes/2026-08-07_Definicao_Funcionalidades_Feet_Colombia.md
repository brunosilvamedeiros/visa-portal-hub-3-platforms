# Ata de Reunião: Definição das Funcionalidades até o Fim de 2026

**Data**: 07/08/2026 | **Artefato produzido**: mapa mental Back/Front → Feet Colombia

## 📝 Resumo dos Pontos Definidos
1. **Carteira**: melhorar a funcionalidade existente — estado de conta, comprovantes de pago e límite de crédito.
2. **Logística**: aproveitar ao máximo o que o **Medusa** já oferece (reduzir desenvolvimento); criar o **módulo de Fulfillment** para o time operar todo o fluxo dentro do sistema; criar o fluxo de **devolução/garantia** de mercadorias.
3. **Contábil**: fluxo simples — a área é **notificada quando o pedido é separado** no fulfillment, **fatura para o cliente** e só então seguem as etapas de entrega (gate de faturamento antes da expedição).
4. **Front do Representante**: verificar o **estudo** realizado (protótipos storefront B2B / Portal Andino) para tornar o front mais funcional para o que o rep necessita, cobrindo as 3 plataformas: Catálogo B2B caja, Catálogo B2B pares e Vitrine Infinita B2B.

## 🧭 Diretriz de Execução
Organizar em **etapas bem separadas, executáveis em paralelo com o mínimo de conflitos** → resultado documentado no [Roadmap de Funcionalidades 2026](../01_Projetos/Feet_Colombia_Roadmap_Funcionalidades_2026.md) (Fase 0 de contratos + 4 frentes WS-A a WS-D).
